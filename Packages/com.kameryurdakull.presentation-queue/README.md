# Presentation Queue

Ekranda yer kaplayan gösterimleri (banner, açılış kartı, ödül animasyonu...) sırayla oynatan UniTask tabanlı kuyruk. VContainer kaydı için `builder.RegisterPresentationQueue()` kullanın.

Kurulum adresleri, kullanım örneği ve davranış ayrıntıları için [depo README dosyasına](https://github.com/kameryurdakull/unity-presentation-queue#readme) bakın. Package Manager > Samples > Basic Usage > Import ile örneği alın.
